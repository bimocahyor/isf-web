# ADR-007: CMS Content Workflow

**Status:** Accepted  
**Date:** 2025

## Decision

A simple workflow-driven CMS for ISF platform articles and announcements.
No third-party CMS is used — the content model is implemented as domain tables in PostgreSQL.

## Content Status Machine

```
DRAFT ──(submit)──► IN_REVIEW ──(approve)──► APPROVED ──(publish)──► PUBLISHED
  ▲                     │                                                   │
  │                  (reject)                                           (archive)
  └─────────────────────┘                                                   │
                                                                        ARCHIVED
```

| Transition | From | To | Who |
|------------|------|----|-----|
| submit | DRAFT | IN_REVIEW | EDITOR, ADMIN |
| reject | IN_REVIEW | DRAFT | REVIEWER, ADMIN |
| approve | IN_REVIEW | APPROVED | REVIEWER, ADMIN |
| publish | APPROVED | PUBLISHED | REVIEWER, ADMIN |
| archive | PUBLISHED | ARCHIVED | REVIEWER, ADMIN |
| unpublish | PUBLISHED | DRAFT | ADMIN |

## Revision History

Every save of article content creates a row in `article_revisions`:
- The current canonical body lives in `articles.body`
- Revisions store `snapshot JSONB` of the previous state
- Revisions are never deleted
- `articles.body` is updated on each save; revisions are the immutable history

## Core Database Tables (Phase 4)

```sql
articles (
  id UUID PK,
  slug VARCHAR UNIQUE NOT NULL,
  title TEXT NOT NULL,
  body TEXT NOT NULL,            -- HTML or Markdown (to be decided Phase 4)
  excerpt TEXT,
  cover_image_key TEXT,          -- S3 object key (not URL)
  status article_status NOT NULL DEFAULT 'DRAFT',
  author_id UUID REFERENCES users(id) NOT NULL,
  reviewer_id UUID REFERENCES users(id),
  published_at TIMESTAMPTZ,
  archived_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  deleted_at TIMESTAMPTZ
)

article_revisions (
  id UUID PK,
  article_id UUID REFERENCES articles(id) NOT NULL,
  snapshot JSONB NOT NULL,       -- full article state at time of save
  revised_by UUID REFERENCES users(id) NOT NULL,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
  -- NO updated_at: revisions are immutable
)

categories (id, name, slug, created_at)
tags (id, name, slug, created_at)
article_categories (article_id, category_id)
article_tags (article_id, tag_id)
```

## Open Question (Resolve in Phase 4)

Should article body use HTML (WYSIWYG editor) or Markdown?
- HTML: richer editing experience, requires server-side sanitization (DOMPurify or sanitize-html)
- Markdown: simpler storage and diff, requires a Markdown renderer

This decision is deferred to Phase 4 implementation.

## Implementation Phase

Phase 4.
